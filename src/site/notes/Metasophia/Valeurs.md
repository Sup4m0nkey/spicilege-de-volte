 #Valeurs
### Qualités :

- Bien ► Positif en valeur / vertu
- Bon ► Agréable et innocent
- Beau ► Harmonieux
- Juste (justice / justesse) ► Concordant et cohérent
- Utile ► Fonctionnel / facilitant
- Efficace ► Efficient

### Charismes

###### Bushido
- Droiture (義, gi / rectitude / rigueur) [Bushido](https://fr.wikipedia.org/wiki/Bushido#Un_code_tr%C3%A8s_strict_?)
- Courage (勇, yū)
- Bienveillance (仁, jin / grandeur d'âme / compassion / générosité)
- Politesse (礼, rei / étiquette / respect)
- Sincérité (誠, makoto / honnêteté) { #MakotoSan}

- Honneur (名誉, meiyō)
- Loyauté (忠義, chūgi)

###### Confucianisme
- Humanisme
- Équité
- Urbanité
- Intelligence
- Honnêteté

###### Endosistance
- Autonomie
- Clairvoyance
- Tempérance
- Persévérance

Les charismes se ressentent, et cette manifestation ressentie est ce qu'on appelle la "Prestance".
